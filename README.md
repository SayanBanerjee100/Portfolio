# Portfolio

A modern, responsive portfolio website built with React, Vite, TypeScript, and Tailwind CSS. Features smooth animations, dark/light mode toggle, and optimized performance.

## 🚀 Features

- **Modern Tech Stack**: React 19, Vite, TypeScript, Tailwind CSS
- **Animations**: Smooth animations with Framer Motion
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Dark/Light Mode**: Theme toggle with localStorage persistence
- **Performance Optimized**: Code splitting, lazy loading, and optimized builds
- **Type Safe**: Full TypeScript support
- **SEO Friendly**: Meta tags and semantic HTML
- **Accessible**: ARIA labels and keyboard navigation

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Linting**: ESLint
- **Testing**: Vitest (planned)

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/SayanBanerjee100/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🚀 Deployment

The project is configured for deployment to GitHub Pages with GitHub Actions.

### Manual Build

```bash
npm run build
npm run preview
```

### Automatic Deployment

Push to the `main` branch to trigger automatic deployment to GitHub Pages.

## 📝 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## 🎨 Customization

- **Profile Image**: Click on the profile image in the Hero section to upload your own photo
- **Theme**: Use the theme toggle in the navbar to switch between dark and light modes
- **Content**: Edit the component files in `src/components/` to update content
